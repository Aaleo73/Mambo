# P9：强调色改为中性色，播放钮改为白色实心

日期：2026-10-04。范围：界面的配色与播放钮外观。是对 `P9-visual-parity.md`「以原版为参考」的一处有意偏离，由用户逐项确认。

## 决策

原版用蓝色（`#0C68B8`）标记输入框聚焦、卡片选中、侧栏当前项、开关和键盘焦点，播放钮是半透明深色玻璃。用户认为这两点与应用整体的中性玻璃风格不符，因此：

| 项 | 原版 | 现在 |
|---|---|---|
| 强调色 | 蓝色 | 中性色：浅色主题近黑 `#202124`，深色主题近白 `#F2F2F2`；压在上面的文字和开关滑块相应反色 |
| 输入框聚焦 | 蓝色 60% 边 | 边加深到黑 38% / 白 45% |
| 卡片选中 | 2px 蓝环 + 白环 | 2px 中性深色环 + 1px 反色细线 |
| 键盘焦点框 | 蓝色 | 中性深色 / 白色 |
| 播放钮（卡片、详情页、播放页） | 半透明深色玻璃、白描边 | 白色实心圆、深色圆角三角；详情页进度环改为深色 |
| 播放页浮层 | 半透明黑底、白描边 | 不透明深灰 `#1C1D21`，无描边，圆角 18 |
| 实心图标 | 尖角 | 描 2.4 的同色圆角边，与线条图标一致 |
| 卡片上浮 | 6px（原版）/ 2px（P9 初版） | 4px，按下 2px |

高对比度主题不受影响，仍然使用系统颜色。

## 没有改的

系统强调色驱动的部分保持 WinUI 默认：输入框里选中文字的高亮。危险操作的红色（关闭按钮悬停、删除类按钮）保留。

## 维护约定

- 不要把 `AccentBrush` 改回彩色；需要彩色状态时新增语义 token（如危险、成功），不要复用强调色。
- 新增实心图标时，路径要比成品轮廓往里收（见 `Themes/Icons.xaml` 的注释）。
- 横向卡片行的固定高度要比「卡片 + 上下留白」多留 2 DIP，否则缩放取整后上浮的卡片顶边会被裁掉（详情页剧集行出过这个问题）。
