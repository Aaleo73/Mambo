# 播放页：画面卡片与标题栏选集开关

日期：2026-10-05。范围：窗口模式下播放页的画面外形和选集栏的收起入口。不改浅色外框、控制层、弹出面板、翻折和全屏。

## 起因

用户觉得播放页割裂。先提出过「播放时把标题栏和选集栏变暗」，用户明确不改浅色外观，该方向作废，不再提。

留在浅色外框内，割裂主要来自画面的边：黑色画面左、下两边顶到窗口边，只有上边留白、上面两个角是圆的，读起来像窗口被挖掉一块，而不是外框上放着一块屏幕。浏览页的内容区是同样的形状，但它和窗口同色，贴边的两边看不出来；换成黑色就很显眼。

选集栏原本就能收起，入口在画面底栏里，底栏自动隐藏后就找不到，用户以为没有这个功能。

## 决策

1. **画面是一张完整的卡片。** 窗口模式下四边各留 12 DIP、四角半径 12；选集栏展开时右边不另留，由选集栏自己的 12 DIP 内边距充当间隔。全屏仍然铺满、无圆角。
2. **选集开关放在标题栏。** 最小化按钮左侧，展开和收起时都在同一位置；提示在「收起选集」「展开选集」之间切换。只在面向播放页且有多集时显示。底栏原来的按钮删除。
3. **收起、展开带淡变。** 选集栏用 `PopupTransition` 只淡变（160 / 120 ms，不位移）。收起时先淡出再折叠，画面那时才变宽；展开时画面先让位，选集栏淡入。全屏、最大化等呈现切换直接落终态。

这取代 `P9-visual-parity.md` 中「黑色画面上留 12 DIP、上角半径 12」和「窗口模式上角半径 12」两处；P9 的其余播放页结论不变。

## 实现与边界

- `PlayerOverlay.UpdateViewportFrame` 是外框边距、圆角和裁剪的唯一出口。圆角属于包含留黑和控制条的最外层 `PlayerFrame`，影片区域保持矩形；`VideoSurface.SetViewportClip(0, topOnly: false)` 撤销内部视频圆角。
- `PlayerFrame` 使用黑色 Border 和 `RectangleClip`，裁切控制条渐变、弹幕和状态层；尺寸变化同步更新，全屏半径为 0，退出全屏恢复 12 DIP。裁剪随冻结退场面保留，在播放层最终销毁时释放。
- 原生 `SwapChainPanel` 的透明度有[平台限制](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.swapchainpanel)：只裁父级合成视觉，实际播放时四角仍会留下矩形黑底，演示画面无法覆盖这一问题。窗口模式的视频宿主四边收进 4 DIP，使原生矩形完全位于 12 DIP 圆角内（所需最小内缩为 `12 × (1 − 1/√2) ≈ 3.515`）；黑框补齐外沿，按新视口正常适配影片，不裁掉影片内容。全屏内缩归零。原生诊断按视频宿主测量交换链，标题和选集布局仍按外框测量。
- 选集栏 `Visibility` 的变化回调负责更新画面边距并通知外壳，动画结束、直接落终态和冻结前的收尾都走这一条。冻结前先落终态再注销回调，退场面的边距与选集栏一致。
- 标题按画面卡片的中心对齐：外壳让出的右侧宽度是「选集栏占用宽度减去卡片左侧留白」，收起时为 0。
- 标题栏按钮登记为 Passthrough，折叠时不登记；`AllowFocusOnInteraction="False"`，点击后键盘焦点留在播放器，空格等快捷键不失效。
- 播放器的 Tab 循环到不了标题栏，原底栏按钮的键盘可达性由新增的 `E` 键补上；全屏时该键不处理，不在看不见选集栏时改偏好。
- 烟测入口 `ToggleEpisodesForSmoke` 不带动画，原有断言语义不变；收起后画面变宽的下限从 200 改为 180 DIP（卡片右侧现在保留 12 DIP）。`PlayerControlsSmoke` 新增三项，经标题栏按钮的真实点击路径验证显示、收起和展开。
- 弹幕诊断的截图模式多停留一次，保存选集栏收起时的窗口。

2026-10-07 修正圆角位置：使用本地生成的宽幅矩形视频经过真实 libmpv 交换链，检查最外层四角露出窗口背景、影片矩形边缘，以及窗口/全屏切换、模式切换、控制条和解绑。演示画面的截图不能代替原生视频的四角检查；真实 Emby 与不同 DPI 下的观感仍由用户验收。

修正后 Debug 构建和 Native AOT 发布成功，741 项测试通过、23 项既有专项跳过；Debug/AOT 播放控件各 50 项检查以及本地真实播放诊断均通过。窗口内原生缓冲区为 2180×1171，全屏为 2560×1600；只截取诊断窗口自身，确认四角不再残留矩形黑底。

## 验证（2026-10-05，本机）

- 独立输出目录的 Debug 构建 0 警告 / 0 错误；`dotnet test` 共 555 项，532 通过、23 按配置跳过、0 失败。
- 弹幕诊断（Debug）通过：标题栏按钮经自动化点击路径收起，`E` 键展开；`PrintWindow` 取到的窗口内容里，画面四角均为圆角、四边留白，收起后标题按画面居中。
- 原生播放诊断（Debug）跑了两轮：第一轮在起播阶段返回 `playback.failed`，尚未出画面；第二轮通过，窗口交换链 2192×1183 与画面视口一致，全屏和还原后的视口均匹配，关闭与解绑完成。第一轮的失败原因未定位，与 P9 记录的起播偶发失败现象相同，不据此认为它与本次改动无关或有关。
- 本地 Native AOT 发布（0.1.4）成功，日志中没有 IL / CS 警告。在该发布目录上，弹幕诊断通过（按钮收起、`E` 键展开，窗口内容与 Debug 一致）；原生播放诊断一轮通过，交换链 2192×1183 与视口一致，全屏、还原、关闭与解绑均通过。
- 完整界面烟测两次都没有进入播放页检查。第一次在 `取得本轮窗口输入` 因 `UiInputTargetOccluded` 退出（窗口被桌面上的其他窗口遮挡）；第二次在 `窗口重新激活与内容区输入` 4 秒内退出，当时前台是任务栏。`PlayerControls` 整段未运行，新增的三项和修改过的下限都没有被这套烟测实际执行过。
- 深色主题下的播放页没有查看。真实视频下的四角裁剪没有截图；依据是同一条裁剪路径下演示画面的截图和原生诊断的视口尺寸。
