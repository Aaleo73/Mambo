# 详情页拖动与播放设置

日期：2026-10-08。

## 决定与原因

- 演职人员采用与剧集相同的 `ScrollView` + `ItemsRepeater`，由 `RailScroller` 处理按住拖动、释放吸附与左右箭头。原 `ListView` 的内层 `ScrollViewer` 会接管滚轮；新轨道忽略原生鼠标滚轮，并关闭 `RailScroller` 的横向/Shift 滚轮处理，使竖向滚轮继续滚动详情页。保持原卡片尺寸、间距和虚拟化。
- mpv 路径整行只在选中外置方式时显示。外置按钮可先选中以配置路径，避免“没有有效路径就无法选择外置，无法选择外置就不能填写路径”的死路。界面待配置选择由 ViewModel 暂存；Core 的实际播放方式仍须通过已有验证才能改为 External，不改变契约、验证器或配置格式。
- 路径验证失败或路径编辑撤销批准时，保留配置入口供重试。切回内置立即隐藏路径；验证完成后重新检查界面选择，避免迟到结果重新启用外置。已完成的方式保存清除暂存选择，继续反映实际设置。
- 「硬件解码」开关改为「解码方式」下拉菜单，外观沿用 HDR 的按钮与菜单。软解对应 `HardwareDecodingMode.Off` / `hwdec=no`，硬解对应 `Auto` / `d3d11va`，保留历史偏好。硬解不可用时仍允许 mpv 自行回退；保留手动软解作为驱动兼容问题的处理入口。

## 验证与限制

- 构建、测试和界面自动回归结果见 [STATUS](../STATUS.md)。界面回归使用假服务，覆盖首次选择外置、验证失败后继续配置、选回内置，以及演职人员拖动、箭头与捕获释放。
- 【需用户】真实片库中演职人员的拖动和滚轮体验，内置/外置切换时的布局，以及两种解码方式的实际播放效果仍需用户确认；自动回归不能代替这些体验验收。
