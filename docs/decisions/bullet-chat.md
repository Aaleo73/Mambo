# 弹幕（内置播放器）

日期：2026-10-05。范围：Core 的弹幕契约、匹配与取数，App 的弹幕合成层和播放页控件。旧项目没有弹幕，这是新增功能；借鉴 [uosc_danmaku](https://github.com/Tony15246/uosc_danmaku) 的匹配流程与排版默认值，没有复制它的代码。代码标识符用 `BulletChat`，界面文字用「弹幕」。

## 决策

| 问题 | 决定 | 原因 |
|---|---|---|
| 渲染 | 原生合成层，叠在视频交换链上方 | mpv 的 `osd-overlay` 随视频帧重绘，24fps 片源的弹幕也只有 24fps（uosc_danmaku 为此提供补帧滤镜）；内置 libmpv 又是 `load-scripts=no`、不收键盘，脚本搬不进来 |
| 数据来源 | 弹弹play 兼容协议，服务器地址是代码里的常量 | 用户要求零设置；见下文"风险" |
| 匹配 | 全自动，手动搜索只用于纠错 | 用户要求 |
| 设置 | 设置页不出现任何弹幕内容；开关与样式在播放页的弹幕面板里。显示区域默认占视频高度的 25% | 用户要求 |
| 外置 mpv | 不介入 | 维持 [外置 MPV 接管](P7-external-handoff.md)"界面与脚本归用户"的决定 |

## 渲染

`BulletChatLayer` 放在 `VideoHost` 内、`VideoSurface` 之后，继承视频区的圆角裁剪，位于输入层与控制层之下。

- **每条弹幕画一次。** `BulletChatTextRasterizer` 用 Win2D 排版并画进 `CompositionDrawingSurface`：先按轮廓描边，再填色；深色字配浅色描边。字体是仓库内的 MiSans Semibold。表情用彩色字形：`CanvasTextLayout` 不继承 `CanvasTextFormat` 上的选项，`EnableColorFont` 必须设在布局上，否则只有单色轮廓。
- **运动交给合成器。** 所有弹幕共用一个合成器时钟（属性集上的 `T`，由线性关键帧动画驱动）。滚动弹幕的横坐标是一条表达式：`layout.W − (clock.T − start) / layout.D × (layout.W + 宽度)`。窗口缩放只改 `layout.W`，调速只改 `layout.D`，在场的弹幕随之连续变化。
- **界面线程只做低频工作。** 100ms 的节拍里提前 1 秒生成即将出现的弹幕、回收已离场的。
- **暂停、继续、变速不跳。** 时钟动画停下时保留当前值，继续时从 `this.StartingValue` 接着走。
- **对时。** `BulletChatClock` 是合成器时钟在界面线程的镜像，与快照里的播放位置比较；偏差超过 0.3 秒（跳转，或累积漂移）才清空并按新时间重建仍在画面内的弹幕。
- **精度。** 合成器时钟用相对秒，每 600 秒整体平移一次零点，避免长片后段 float 精度不足。
- **分轨。** `BulletChatLanePlanner`：滚动弹幕进轨需要前一条尾部已完全进入画面，且新弹幕在前一条离开前追不上它；没有可用轨道就丢弃。顶部、底部固定弹幕各自分轨，停留 5 秒。

### Win2D 与 Native AOT

`Microsoft.Graphics.Win2D` 1.4.0 声明依赖 `Microsoft.WindowsAppSDK.WinUI >= 1.8`，本仓库是 WindowsAppSDK 2.5.1。验证结果：

- Debug 构建与 Native AOT 发布均零警告零错误，`Microsoft.Graphics.Canvas.dll` 随产物发布。
- `scripts/test-bullet-chat.ps1` 在 Debug 与 AOT 产物上各通过一次：离屏读回像素确认描边、填充、透明区域和彩色表情都存在；随后用演示播放走完加载、跳转重建、时钟推进、暂停保持、继续不跳、`D` 键开关、弹幕面板改样式并落盘、搜索并手动选集、倍速面板与轨道面板的打开和选择、关闭后零残留。两次的像素统计完全一致。
- 交给 XAML 列表控件的集合必须是具体类型（`List<T>`、`ObservableCollection<T>`）。集合表达式赋给只读接口时，编译器合成的集合类型没有 WinRT 投影，`ItemsSource` 会当场抛参数错误。
- 免打包应用里 Win2D 的自定义字体只有 `file:///…#MiSans` 这种写法生效，`ms-appx:` 和相对路径都不行；光栅化器在启动时逐个尝试，都不行时退回 Segoe UI。

## 数据来源与自动匹配

`IBulletChatService` 跟随 `IPlaybackService` 的当前条目，切集即自动加载。弹幕关闭、外置播放或没有播放时保持 Idle，不发任何请求。只把剧名、季号、集号发给弹幕服务器，不发送 Emby 地址、令牌或文件路径；请求的 User-Agent 是 `Mambo/<版本>`。

匹配流程（`DandanplayBulletChatProvider` + `BulletChatMatcher`）：

1. **记忆。** 这一季匹配过，就按记住的条目和位置偏移直接取集。
2. **搜索并打分。** 用剧名搜索；整个片名搜不到时，用主标题或前半段再搜一次。候选按下列信号打分：
   - 标题相似度（去掉季标记和分段标记后的 Jaro-Winkler），低于 0.75 淘汰；同年上映的剧场版放宽到 0.7。
   - 季标记（第N季、Season N、罗马数字、尾部数字）：与目标季不同的淘汰。
   - 首播年份：相同、相差一年、相差更多。
   - 类型：剧集不配剧场版；正片优先于总集篇和特别篇。
   - 该季集数：与媒体库这一季的集数相同的加分。
   - 开播次序：各季用副标题命名时，按开播先后的第 N 部 TV 动画多半是第 N 季。
3. **取集。** 同一季拆成前篇/后篇、Part 2 的，按开播顺序接成一条链，取其中第 N 集；各分段从 1 起编号、季内续接编号、全作品绝对编号三种情况都能处理。
4. **顺延。** 媒体库把多季编成一季（绝对集号）时，顺延到同一作品的后续条目。
5. **兜底。** 用"剧名 S02E03"调文件名匹配接口，只在第一名明显领先时采用。

手动搜索选定的结果优先于自动结果，并同样按位置偏移让这一季后续各集沿用。

**繁体转简体。** 用户验收后要求自动转换，不设开关。取弹幕时带 `chConvert=1`，由服务器把全部弹幕（含关联来源）转成简体。
实测《葬送的芙莉莲》第二季第 1 话 4273 条里有 1804 条是繁体。没有用 Windows 的 `LCMapStringEx` 在本地转：它是逐字映射，
同一批数据里有 134 条与服务器结果不同，漏掉的都是常用词（終於、怎麼、後、乾洗、夥伴）。缓存键带上了转换方式，此前缓存的未转换响应不会被复用。

**垃圾弹幕。** 弹幕库里混有被当成文本的二进制数据（实测《药屋少女的呢喃》第 1 话在 0 秒处有 4 条）。解析时丢弃带控制字符的弹幕，以及同一发送者的其余弹幕——后者往往也是垃圾，只是恰好没有控制字符。换行和制表符不算。

### 与计划不一致的地方

- **文件名匹配接口。** 计划写的是 `fileNameOnly` 模式、只接受服务器判定为唯一的结果。实测该服务器只接受 `hashAndFileName`，且返回的是一串猜测。现在的做法：用文件名摘要占位哈希，对返回的猜测按同样的规则打分，第一名领先 0.2 以上才采用。
- **打分信号比计划多。** 类型偏好、该季集数、开播次序、分段链、电影放宽阈值与前缀重搜，都是对线上数据实测后补上的（《鬼灭之刃》各季用篇名、《进击的巨人》第三季分前后篇、《铃芽之旅》在弹幕库里叫《铃芽户缔》）。
- **演示数据的类名。** 计划写 `FakeBulletChatService`；实际是 `FakeBulletChatProvider`，与真实实现共用同一个 `BulletChatService`，跟随播放的逻辑只有一份。
- **面板代替菜单。** 计划写的是照轨道菜单做子菜单。子菜单的弹出层是系统亚克力样式，与"画面上方不用亚克力"冲突，改成一个实底面板：开关、四个滑块、匹配状态、搜索。用户验收后要求倍速和字幕/音轨也用同样的样式：两者改为 `PlayerChoicePanel`（带标题的选项列表，当前项打勾），三个面板共用 `Themes/PlayerPanels.xaml` 里的样式，原来的 `MenuFlyout` 及其样式已删除。
- **默认显示区域。** 计划写的是 0.85，用户验收后改为 0.25。`BulletChatSettings.DefaultsVersion` 记录默认值的版本：仍停在旧默认值 0.85 上的设置迁移一次，用户自己选的值保留，之后再选 0.85 也不会被改回。

## 风险与限制

- **默认服务器是 uosc_danmaku 作者的个人代理**（`https://danmaku-api.152468.xyz`），可能失效。因为不留设置项，届时要改 `DandanplayClient.DefaultServer` 并重新构建；任何弹弹play 兼容服务都可以替换。
- **服务器会限流。** 实测短时间内连续约 40 次请求后返回 429。正常播放每集 3–4 次请求，且弹幕缓存 6 小时、搜索与剧集信息缓存 24 小时；被限流时状态为失败，面板里可以重试。
- **没有复制插件内置的弹弹play 凭据**，也没有实现官方接口的签名鉴权。
- **匹配依赖媒体库的元数据。** 剧名与弹幕库差异大、且没有共同前缀时会匹配不到；第 0 季的特别篇和没有集号的剧集不自动匹配。这些情况用面板里的搜索手动指定一次即可。
- **顶部固定弹幕与滚动弹幕共用上方的行**，高密度时会叠在一起，与常见弹幕播放器一致。
- **简体转换依赖服务器。** 换用别的兼容服务时，如果它不理会 `chConvert`，繁体弹幕会原样显示。
- **本期不做：** 哈希匹配、站点爬虫、类型过滤、时间偏移、屏蔽词、合并重复、发送弹幕、外置 mpv。
