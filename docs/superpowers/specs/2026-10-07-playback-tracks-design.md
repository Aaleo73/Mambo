# 字幕、音轨与字幕样式增强设计

日期：2026-10-07。

状态：用户已选定本轮范围并修订行为；本文待用户审阅，尚未进入实现。本文中的验收均为计划，不代表已经通过。

## 1. 目标与范围

让内置播放器能够按首选语言和上次选择选轨、清楚区分轨道、调整字幕时间与样式，并将拖入的本地字幕保存到软件管理的目录，按影片或剧集关联后自动加载。

用户明确澄清：手动选轨成功后自动保存并在后续播放恢复，但界面不展示“记忆”功能。不提供保存选择按钮、记忆开关、清除记忆入口、记忆徽标或成功提示。再次选轨自然替换原选择。首选语言和字幕样式同样自动保存；拖入字幕持久保存且可以批量关联到其他单集，仅处理归属明确的文件，无法确定归属的静默跳过，不显示分配面板或导入说明；字幕延迟只作用于当前条目。

本轮不包含播放信息面板、快进步长、时间跳转、选集搜索或连播行为改动。外置 mpv 继续使用自身的配置、字幕和拖放操作。输入框光标修复随之后的功能版本交付，不为它单独发布版本。

## 2. 首选语言

在现有设置页的播放器设置中增加两个选项，注明“下次打开内置播放时生效”。会话创建时取得设置快照，当前正在播放或连播的会话不因设置编辑突然切轨。

| 设置 | 选项 | 默认 |
|---|---|---|
| 首选音轨语言 | 自动、中文、日语、英语、韩语、法语、德语、西班牙语、俄语 | 自动 |
| 首选字幕语言 | 自动、中文、日语、英语、韩语、法语、德语、西班牙语、俄语、默认关闭 | 中文 |

语言存储使用稳定代码而非中文显示名称。音轨的“自动”沿用片源和 mpv 默认；字幕的“中文”沿用现有中文优先、英语回退顺序，兼容旧设置文件。其它首选语言找不到时交回 mpv 默认选择，不根据文件名推测语言或强行选择列表第一项。“默认关闭”仍允许当集手动开启或拖入字幕。

音轨的选择顺序是：当集明确手选 → 能可靠匹配的本剧/本片上次选择 → 首选语言 → mpv 默认。字幕的选择顺序是：当集明确手选 → 当前媒体项目明确保存的选择 → 此项目导入时指定采用的本地字幕 → 能可靠匹配的整剧上次选择 → 首选语言 → mpv 默认。关闭字幕也是明确选择；文件缺失或无法可靠匹配时继续回退。音轨和字幕的手选保护分别管理。

首选语言通过 libmpv 的语言选择能力接入；上次选择由 Core 在获得轨道元数据后恢复。内封字幕和服务器外挂字幕共同参与选择；没有当集手选时，稍后到达的匹配字幕可以被自动启用，但不能因此阻塞视频开播。

### 2.1 自动保存与恢复

- 仅内置播放器成功执行的用户音轨/字幕选择产生记录；关闭字幕保存为明确的关闭状态。自动选择、引擎属性通知、缺轨回退和失败命令不改写记录。
- 按服务器与账号隔离；剧集按 `SeriesId` 覆盖整部剧并跨季沿用，电影和没有 `SeriesId` 的项目按 `ItemId` 保存，不用标题猜测归属。音轨、字幕分别记录，最近最多保留 500 个内容项目，超出时淘汰最早更新项。
- 记录规范化语言、安全标题特征、强制标志以及编码、声道等辅助信息，不保存 mpv 轨道 ID 或列表序号。优先恢复唯一明确匹配；存在歧义时回退首选语言和默认规则，不猜选第一条同语言轨道，也不覆盖旧记录。
- 有区分性标题的原选择不能仅凭语言相同恢复。没有区分性标题时，只有相同语言和强制标志的候选唯一，才允许宽松匹配。
- 改动某类首选语言时自动使该类已有选轨记录失效，避免旧选择一直压住新设置。另一类记录保留；当前会话按原设置继续，下次打开播放采用新语言。旧会话或异步结果不得写回已失效的记录。
- 本地字幕用持久字幕库中的不透明字幕 ID 保存选择，按具体 `ItemId` 恢复，不能将第 1 集字幕沿用到整部剧。原始拖入路径不保存；受管副本的相对路径和安全显示名称由字幕库维护。
- 为某项目导入字幕是明确的采用意图：该项目本批第一条成功关联的字幕成为当前媒体项目的采用项，替换先前的采用项；其余版本保留为可选轨道。之后手动选其他轨道或关闭字幕会自动更新本项目的选择，不能下次又强行切回导入文件。没有本地字幕的项目继续按整剧选择恢复。
- 首选语言变更不删除字幕文件或媒体关联；失效的手选记录按上面的顺序回退，已导入字幕仍可自动加载。500 项选轨偏好的淘汰不删除字幕库文件、关联或各项目的导入采用项。
- 保存失败不撤销已经成功的切轨；显示普通“设置保存失败”提示并记录安全错误。正常保存和缺轨回退均不显示额外的记忆提示。

## 3. 轨道菜单

沿用现有控制组件的“字幕 / 音轨”入口，在同一面板内展示两组轨道，字幕组下方直接放置时间与样式调整控件。打开现有字幕控制组件后即可修改，不增加“字幕样式”入口、子面板或二级页面。

- 轨道展示使用安全标题、语言、编码；音轨补充已有的声道信息。明确来源可显示“内封”“外挂”或“本地”。缺失字段直接省略。
- “评论音轨”“双语”“简体/繁体”等仅展示片源明确提供的信息，不凭语言代码或顺序猜测。
- 相同展示信息的条目使用本次列表序号区分。序号和 mpv 轨道 ID 都不用于持久化。
- 保留字幕关闭选项、当前勾选和现有 C / V 快捷键。删除“记住选择”“清除记忆”等拟议入口。
- 原有每组最多 32 项的公开契约继续有效。已选轨道必须可见，优先保留已选项及当前项目的本地字幕。每个媒体项目最多关联 32 条本地字幕，超过时静默跳过该项目的超出部分；批次中其他项目继续处理。

用户主动拖入的字幕允许显示经过清理的文件名部分，例如“简中.ass · 本地 · ASS”。这是用户本机提供内容的展示例外；mpv 的原始 `external-filename` 不传到界面，也不展示目录。相关契约注释和规格随实现一起修订。

## 4. 字幕时间调整

- 提供“提前 0.1 秒”“延后 0.1 秒”、数值输入和“归零”。允许范围为 -60.0 到 +60.0 秒，精度 0.1 秒。
- 正数表示字幕更晚出现，负数表示更早出现；使用明确的“提前 / 延后”文案。非法输入原位提示，既不提交也不静默截断。
- 显示实际生效值，命令失败保留上一次成功值，提示错误；不因调整失败停止视频。
- 当前没有字幕时禁用调整。暂停和跳转保持偏移；切集、换片源、换成另一条字幕或关闭字幕时归零。再次选中同一条已选字幕不归零。
- 同一播放条目和片源上的缓冲恢复保留偏移；显式重试重建播放条目、退出播放或重新打开则回到 0。不保存到磁盘，不按剧传播。
- 设置与观察 `sub-delay`，由 Core 快照传递实际状态，UI 不直接访问 Player。

## 5. 字幕样式

### 5.1 控件、默认值与保存

在现有字幕控制组件内直接提供以下五项和“恢复默认样式”，与选轨、字幕时间调整放在同一层。控件直接可见，无需再次点击展开样式区域或进入另一层设置；空间不足时在当前组件内滚动。样式是本机全局的观看偏好，不按影片另存；当前内置播放即时预览，成功应用后自动保存，之后播放继续使用，不增加保存按钮。

| 控件 | 范围与行为 | 默认 |
|---|---|---|
| 字体 | MiSans 和本机已安装字体；不可用时回退 MiSans；不导入字体文件 | MiSans |
| 字号 | 18–72，按 720 高度基准随播放器尺寸缩放 | 38 |
| 文字颜色 | 不透明 RGB 颜色选择器 | 白色 |
| 描边粗细 | 0–6；0 表示关闭，描边为黑色 | 1.65 |
| 底部距离 | 0–180，按相同 720 高度基准缩放 | 34 |

默认字体沿用应用当前配置，其余值对应当前锁定播放器的默认样式。恢复默认样式只重置本节样式字段，不触及轨道记录、语言选择或时间偏移。首版不增加阴影、背景框、字距和行距设置。

调整可在暂停时预览；快速拖动合并为最新值，不能让迟到结果覆盖较新的值。某次样式应用失败时恢复上一个成功应用的整套样式，不写入失败值，不打断播放。保存失败保留已生效画面并提示“设置保存失败”。

### 5.2 不同字幕类型

- 普通文本字幕（包括 SRT/VTT）应用上述基础样式。
- ASS/SSA 默认保留文件自带的字体、颜色、定位和排版。同一字幕控制组件内提供“覆盖字幕原样式”，默认关闭，作为全局样式设置自动保存；关闭时明确提示“当前字幕使用自带样式”，基础样式控件对当前 ASS/SSA 不可调。
- 开启覆盖后应用统一基础样式，提示“可能影响字幕特效与排版”。采用 mpv 支持的样式覆盖方式，不使用 `strip` 主动剥离全部 ASS 标签；不承诺覆盖所有定位/动画标签或保留全部原特效。关闭覆盖后恢复脚本原样式，不修改字幕文件。
- PGS、VobSub 等图片字幕显示“图片字幕不支持文字样式”，本节控件禁用；仍允许时间校正。图片缩放、移位不在本轮范围。
- 类型未知时提示“暂无法调整此字幕的样式”，不提供操作后没有效果的控件。未选字幕时可以编辑供后续文本字幕使用的样式，但不伪装成当前视频已有预览。

底部距离使用文本边距，字号使用文本字号；不以全局 `sub-scale` 或 `sub-pos` 代替所有样式控制。字体、颜色、描边、边距和 ASS 覆盖模式通过类型化契约下发，具体 mpv 属性名只在后端和 Player 出现。

## 6. 本地字幕持久导入与自动关联

### 6.1 接受范围

内置播放器已加载文件后接受拖放，播放、暂停或缓冲时均可用；尚未加载、失败或关闭过程中不接收。窗口、最大化和全屏的画面区域使用相同行为。保留系统拖放光标反馈，不增加拖入说明或覆盖面板。

首轮支持独立的 `.srt`、`.ass`、`.ssa`、`.vtt` 文件，大小写不敏感。目录、压缩包、文本 URL、没有可读取文件路径的虚拟附件，以及 `.idx + .sub` 等成对字幕不在本轮范围。扩展名仅作入口筛选；最终是否能加载由 libmpv 的结果确认。

### 6.2 保存目录与文件归属

按用户“软件目录”的要求，设计使用 `Mambo.exe` 同级的 `Subtitles/`，安装版和便携版采用同一规则。目录不可写时静默终止对应导入，不改存到另一个位置，不登记为已保存，当前播放和原有字幕保持不变。

- `Subtitles/<账号作用域哈希>/files/` 存储受管副本，文件名采用内容 SHA-256 加规范化扩展名，避免标题、源目录和特殊文件名影响路径。
- 同作用域的 `index.json` 保存字幕 ID、内容摘要、相对文件路径、安全显示名称、格式、媒体关联及采用项。索引使用 JSON 源生成、原子替换和备份；不记录服务器地址、令牌、密码或源文件完整路径。
- 关联最终以账号作用域与服务器媒体 `ItemId` 为准；剧名、季集号仅用于导入阶段定位。导入其他单集后，未来播放直接按媒体 ID 查找，不反复猜文件名。
- 先将源文件只读复制到受管临时文件并计算摘要，再完成受管文件与索引提交；索引成功后才将字幕纳入可加载项目，全程不显示导入结果提示。失败不留下可见的半条记录、不破坏已有字幕，且可以重新拖入重试。
- 相同目标与相同内容复用原文件和关联；同名但内容不同保存为另一版本，不覆盖旧内容。相同内容可复用副本，但不能据此自行给其它媒体建立关联。
- 原文件保持不变；移动或删除原文件不会影响 Mambo 后续使用。文件不上传到 Emby。
- 此目录属于持久用户资料，不属于缓存。清除缓存、结束播放、切集、账号注销、升级或卸载不得清理其中已提交的字幕。取消导入只清理本次未提交的临时文件。
- 发布脚本、安装包和更新清单排除 `Subtitles/`，防止把本机导入资料打包分发。更新/卸载只处理发布文件；测试需明确覆盖此保留目录。

### 6.3 季集号与所属剧匹配

拖放开始时捕获当前账号、影片或剧、季和条目身份作为上下文。只解析本批显式拖入的文件，不扫描相邻目录。匹配基于服务器真实元数据；当前连播队列只覆盖当前季且可能降级成单项，不能用其缺项判断“没有这一集”。需要时使用既有完整分页读取目标季元数据，不能引入固定集数上限。

| 文件特征 | 自动关联规则 |
|---|---|
| `剧名.S02E03.ass`、`剧名.2x03.srt` | 所属剧已确定后，按真实第 2 季第 3 集唯一匹配 |
| `第二季 第三集.ass`、`第2季第03集.srt` | 支持阿拉伯数字及常见中文整数；无剧名前缀时采用当前剧上下文 |
| `第03集.ass`、`第03话.srt`、`03.srt`、`03.chs.ass` | 所属剧和目标季明确时按该季第 3 集唯一匹配；无前缀时采用当前剧和当前季 |
| 没有季集号的单个文件 | 没有与当前媒体冲突的剧名/季集信息时，按用户拖入当前播放器的意图关联当前媒体 |
| 多集范围、冲突编号、无编号批次、同号多项、元数据缺失 | 无法唯一确定归属的文件静默跳过，不按文件顺序、总集数或当前位置猜测 |

仅识别明确的季集模式或独立数字字段；年份、分辨率、校验码和版本号不能当成集号。缺少季号不等于第 0 季，`S00` 只匹配服务器实际存在的特别篇。无季号的绝对集数不自动换算成其它季内集数。

剧名只作有限规范化：大小写、空格、点和下划线，以及明确的格式/分辨率/语言标记。已有明确剧名前缀与当前剧规范化后相同，可使用当前剧；其它名称只在服务器搜索得到唯一同名剧时自动关联。英文 release 名与中文译名、简称、同名重拍或未知前缀不使用模糊相似度自动落盘。

混合不同剧的批次按文件名前缀分组，只自动处理能唯一确定剧、季和单集的文件，其余静默跳过。没有所属剧信息的文件使用当前上下文；有不一致剧名前缀的文件不能因为季集号相同而全部落到当前剧。不提供选择目标剧、季或单集的入口。

### 6.4 静默处理

唯一匹配的文件直接复制并保存关联，不要求用户点击“保存”或逐项确认。无法确定归属的文件不复制、不建立关联，直接跳过；批次中已明确匹配的文件继续导入。全部无法确定时不导入任何文件，也不改变当前字幕。单个无季集号且没有冲突信息的文件仍按第 6.3 节关联当前媒体。

不显示分配面板、目标选择、确认按钮、成功提示、跳过说明或汇总通知，也不建立等待后续分配或未来播放时继续猜测的悬空关联。不支持、超出容量、无法读取、复制或索引失败的文件同样静默跳过，已提交的成功项保留。导入与自动加载结果仅通过实际字幕和正常轨道列表体现；失败只记录脱敏后的稳定错误码。

文件扩展名和可读取性验证不等于已验证实际字幕渲染。其它单集的字幕导入时不加载到当前视频；未来加载失败时静默回退，并保留可用视频及其它字幕。

### 6.5 播放与多版本采用

- 属于当前媒体的字幕导入后加入菜单并立即启用本组第一条成功项；换字幕时偏移归零。只包含其它单集字幕的批次不改变当前视频的字幕。
- 每个目标允许多个版本；批次中的第一条成功关联项成为该目标的采用项，其余作为候选保留。之后正常切轨即可自动改变本项目下次采用的字幕，没有“保存选择”或“记忆”界面。
- 下次打开影片、重试或播放对应单集时，自动读取受管副本、加入菜单并按第 2 节的顺序选择。即使源文件已移动、应用已重启或此前已退出登录，重新进入同账号仍可使用。
- 重复导入已存在的关联直接采用原条目，不制造重复轨道；该轨道已在使用时保留当前延迟。修改了源文件内容后再次拖入，会按新版本导入。
- 切集释放引擎内当前轨道与临时句柄，不删除持久副本。账号之间不共享媒体关联；媒体不存在、受管文件丢失或损坏时静默回退，不把文件套用到其它媒体。

### 6.6 异步与生命周期

文件匹配和复制不阻塞播放会话收件箱。已确定的归属绑定到导入开始时的账号和媒体；导入过程中自然连播或切集不能改变文件归属。账号切换取消尚未提交的旧账号工作，不回滚之前已提交的项目，也不能写到新账号。

“保存关联”和“现在启用”分开处理：保存使用确定的媒体身份；立即启用还必须核对当前条目代际与用户操作代际。只比较 `ItemId` 不够，同一集可能已重新播放。保存期间发生了更晚的选轨、关闭字幕或再次拖放，旧结果不能抢回当前选择；这些新操作也需与相应项目的下次采用记录保持一致。

拖入、持久字幕自动加载、上次选择恢复、首选语言及服务器字幕到达经过统一的轨道选择逻辑。手选保护既约束 C# 自动选择，也约束 `sub-add` 的原生选择副作用。当前 `sub-add ... auto` 在部分情形仍可能触发默认选择，不能将其当成绝对的“不切换”。

播放关闭取消尚未完成的原生加载，应用退出取消未提交的文件事务并等待安全收尾。旧加载事件不得污染新条目；完成结果关联到条目代际，需要取消或清理时只处理自己加载的轨道。持久字幕、Emby 下载的临时字幕、拖入的源文件分别管理。

## 7. 模块与契约

数据流：WinUI 拖放 / 设置 / 轨道面板 → `Mambo.Core.Contracts` → Core 播放会话 → `IPlayerEngine` → libmpv；实际状态沿引擎事件 → Core 快照 → ViewModel 返回。

- `AppSettings`：增加音轨语言、字幕语言和类型化字幕样式设置；旧字段缺失使用上文默认，未知值回退默认。继续使用 JSON 源生成和现有原子设置存储。
- Core 内部的轨道偏好服务负责按账号和内容记录、恢复手选；复用现有画质偏好的作用域与容量管理方式，不向 UI 暴露记忆状态或清除接口。账号切换和语言偏好失效均保护并发保存。
- 新增 Core 持久字幕库，分离文件复制/索引、文件名解析、媒体关联和自动装载。由组合根提供软件目录的受管存储路径；不借用 `cache/playback-subtitles` 或临时字幕释放逻辑。
- Contracts 提供绑定当前播放上下文的字幕导入请求；自动匹配、文件跳过与关联提交全部由 Core 处理，不提供候选媒体列表或手动分配契约。UI 通过正常轨道快照获取已加载结果，不展示导入状态。持久索引、账号键和真实受管路径都留在 Core，UI 不接触 Emby DTO。
- `IPlaybackSession`：增加字幕延迟、字幕样式和导入后当前条目的字幕装载能力。既有选轨命令保留并自动保存适用的用户选择，交互命令明确绑定当前条目，防止排队后作用到新条目。
- `SessionSnapshot`：增加字幕实际偏移、实际样式及其适用能力、本地字幕受理能力和不透明条目代际。代际不含服务器 ID、路径或令牌。
- `TrackInfo`：增加必要的安全展示字段与来源标识。UI 不接收原始 mpv 属性树或 Core DTO。
- 本地字幕请求持有源路径的类型必须覆盖 `ToString()`，避免隐式输出路径；源路径仅用于本次复制，不持久化、不进入快照、日志或异常正文。持久索引只保存软件受管目录内的相对路径。
- Core 分离语言选项转换、轨道匹配与投影、样式应用和本地附件登记，避免将所有规则继续堆进 `PlaybackSession`。需要的拆分只服务本轮功能。
- `PlayerOverlay` 负责 WinUI Drop 与现有 `TracksPanel` 内的选轨、时间及样式交互，`VideoSurface` 保持显示职责；样式控件直接整合进字幕控制组件，不新增样式子面板。拖放数据使用系统文件对象，传给 mpv 的命令使用参数数组。
- 拖入源文件、持久副本与 Core 下载的临时字幕分别登记。临时字幕清理路径不能接触前两者；安装、更新、缓存清理和发布打包均遵守持久字幕目录边界。

全套实现保持 AOT 兼容；XAML 只放 App，界面绑定使用 `x:Bind`，前端只使用 Contracts 和现有 VideoSurface 公开 API。Fake 会话同步支持新契约，演示模式不访问真实用户文件。

## 8. Emby 上报与错误

用户拖入的轨道不属于服务器媒体源，不能把其 `ff-index` 误映射为 Emby 字幕索引。服务器原有轨道继续准确映射；本地字幕选中时上报省略对应的服务器字幕索引，不发送文件名或路径。

本轮不实现服务器远程字幕校时。现有上报中固定为 0 的 `SubtitleOffset` 改为省略可选字段；本地偏移的真实状态只在播放器中展示。公开 Emby 文档对该字段类型的描述存在差异且未明确单位，本轮不猜测单位，也不把本地校时写入服务端偏好。

本地字幕导入及自动加载遇到无效文件、加载失败、容量用尽或目标条目过期时，按第 6.4 节静默处理，仅记录稳定错误码，不通过通用错误处理再次触发通知；批量处理部分失败保留成功项，加载失败不关闭视频，原字幕保持可用。用户主动调整字幕时间或样式的错误仍使用相应章节的固定中文提示。原始 I/O 异常、原生输出与文件完整路径不进入日志。

## 9. 验证与完成标准

实现阶段需要覆盖：

1. 旧设置兼容、首选语言转换、下次会话生效、手选自动跨集/重启恢复、账号隔离、容量淘汰；改语言后相应旧选择失效，UI 没有记忆入口或提示。外置 mpv 不被设置覆盖。
2. 同语言多轨、缺失字段、重复标题、轨道 ID 改变、歧义回退不覆盖旧记录、容量上限、选中项可见及字幕关闭。
3. 延迟的正负方向、0.1 秒步进、范围和失败回退；暂停/跳转保留、切集/换轨清零。
4. 单个/多个字幕、重复内容、同名新版本、不支持文件、部分成功、目录不可写、复制/索引失败及重试；导入、跳过、失败和自动加载均不显示额外提示或面板；源文件保持不变，移动源文件后仍可播放受管副本。
5. 拖放数据迟到、导入中自然连播/切集、账号切换、同集重播、字幕下载晚到、关闭字幕与再次手选的竞争；已确定归属不改变，当前用户选择不被旧结果覆盖。
6. 本地字幕索引与 Emby 索引碰撞、停止上报和临时文件清理；无路径、文件内容或凭据泄漏。
7. 真实无头 libmpv 加载合成 SRT/ASS 并观察轨道和 `sub-delay`；界面专项验证输入焦点、Esc、拖放与控制层隐藏。
8. 样式默认兼容、范围与未知字体回退、实时修改和重启恢复、快速拖动/切集竞态、失败恢复整套样式；现有字幕控制组件直接提供全部样式控件，无二级入口，空间不足时可在组件内滚动并用键盘访问；文本字幕实际渲染、ASS 原样式保留/覆盖切换、图片字幕适用性提示。无头属性检查不能替代实际显示验证。
9. `SxxEyy`、`1x02`、中文季集、纯集号、多季、特别篇、第 801/1001 集、缺失元数据、同号多项、英文译名不一致和跨剧混合批次；不能把分辨率/年份当集号，不能因当前队列缺项截断关联。无法确定归属的文件不复制、不建关联、不显示分配入口；部分可匹配时只导入明确项，全部不可匹配时当前状态不变。
10. 重启、显式重试、换集和同账号重新登录后的自动装载与采用；多个字幕版本、关闭状态优先、内容摘要去重、文件丢失/损坏及回退。
11. 清除缓存、升级和卸载保留持久字幕；安装包/便携包/更新清单不包含运行时导入资料；导入失败只能清理本次临时文件，不能删除已提交或用户源文件。

代码改动完成后运行 `dotnet build -p:Platform=x64`、`dotnet test`，以及对应 Native AOT 发布和针对本轮变更的界面检查。已完成的旧阶段验收不重新执行。

【需用户】从文件资源管理器拖入真实 SRT/ASS 和一批同剧不同集字幕，确认归属、保存、重启及播放对应单集时的自动采用；混入无法确定归属的文件，确认其被静默跳过，整个过程没有分配面板或额外通知；确认校时、暂停/全屏、字号、颜色、描边、底部距离及 ASS 保留/覆盖时的实际观感；用真实 Emby 片源确认选轨恢复和服务器外挂字幕晚到时不覆盖当集手选。自动化结果不能代替这些人工检查。

完成标准：语言偏好、自动选轨恢复、轨道菜单、字幕时间与样式、持久字幕导入及批量关联均可经正常界面使用；字幕样式在现有控制组件中直接修改；选轨自动保存且无记忆界面；字幕受管副本跨重启和换集保留，并在正确媒体上自动采用；归属不明的文件静默跳过，导入及自动加载不显示分配面板或额外提示；失败不打断原视频；构建与必要测试通过，人工项状态如实记录。
