# 前后端请求

需要对方修改它负责的路径时，在下表新增一条请求。处理方完成后更新"状态"。分歧无法解决时，交给用户决定。所有权见 `docs/PLAN.md` §14.1。

- **编号**：按顺序递增，格式为 R-001、R-002……
- **内容**：写清背景、期望的接口或行为、涉及的契约类型。
- **阻塞**：填"是"表示提出方在这件事完成前无法继续。
- **状态**：待处理 / 已完成 / 已拒绝（附理由）。
