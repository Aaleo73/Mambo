# 字幕与音轨增强设计

日期：2026-10-07。

状态：用户已选定本轮范围并修订行为；本文待用户审阅，尚未进入实现。本文中的验收均为计划，不代表已经通过。

## 1. 目标与范围

让内置播放器能够按首选语言选轨、清楚区分轨道、调整当前字幕时间，并接受拖入的本地字幕。

用户明确要求不保存手动选轨记忆，也不提供清除记忆入口。因此只有用户主动配置的语言首选项持久化；当前条目的手选状态、字幕延迟和本地字幕附件只存在于播放会话中。

本轮不包含播放信息面板、快进步长、时间跳转、选集搜索或连播行为改动。外置 mpv 继续使用自身的配置、字幕和拖放操作。输入框光标修复随之后的功能版本交付，不为它单独发布版本。

## 2. 首选语言

在现有设置页的播放器设置中增加两个选项，注明“下次打开内置播放时生效”。会话创建时取得设置快照，当前正在播放或连播的会话不因设置编辑突然切轨。

| 设置 | 选项 | 默认 |
|---|---|---|
| 首选音轨语言 | 自动、中文、日语、英语、韩语、法语、德语、西班牙语、俄语 | 自动 |
| 首选字幕语言 | 自动、中文、日语、英语、韩语、法语、德语、西班牙语、俄语、默认关闭 | 中文 |

语言存储使用稳定代码而非中文显示名称。音轨的“自动”沿用片源和 mpv 默认；字幕的“中文”沿用现有中文优先、英语回退顺序，兼容旧设置文件。其它首选语言找不到时交回 mpv 默认选择，不根据文件名推测语言或强行选择列表第一项。“默认关闭”仍允许当集手动开启或拖入字幕。

每个条目的选择顺序是：当集明确手选（包括关闭字幕和成功拖入字幕）优先于语言首选与默认规则。当集手选不写入设置、不传递到下一集；再次打开同一影片仍使用语言首选。音轨和字幕的手选保护分别管理。

首选语言通过 libmpv 的语言选择能力接入，不另建跨集轨道匹配或偏好数据库。内置文件和服务器外挂字幕共同参与自动选择；没有手选时，稍后到达的匹配字幕可以被自动启用，但不能因此阻塞视频开播。

## 3. 轨道菜单

沿用现有“字幕 / 音轨”入口，在同一面板内展示两组轨道，并在字幕组下方提供时间调整。

- 轨道展示使用安全标题、语言、编码；音轨补充已有的声道信息。明确来源可显示“内封”“外挂”或“本地”。缺失字段直接省略。
- “评论音轨”“双语”“简体/繁体”等仅展示片源明确提供的信息，不凭语言代码或顺序猜测。
- 相同展示信息的条目使用本次列表序号区分。序号和 mpv 轨道 ID 都不用于持久化。
- 保留字幕关闭选项、当前勾选和现有 C / V 快捷键。删除“记住选择”“清除记忆”等拟议入口。
- 原有每组最多 32 项的公开契约继续有效。已选轨道必须可见；本地字幕超过可展示容量时拒绝新增加载并给出明确提示，不出现“加载成功但菜单找不到”。

用户主动拖入的字幕允许显示经过清理的文件名部分，例如“简中.ass · 本地 · ASS”。这是用户本机提供内容的展示例外；不读取或展示 mpv 的原始 `external-filename`，也不展示目录。相关契约注释和规格随实现一起修订。

## 4. 字幕时间调整

- 提供“提前 0.1 秒”“延后 0.1 秒”、数值输入和“归零”。允许范围为 -60.0 到 +60.0 秒，精度 0.1 秒。
- 正数表示字幕更晚出现，负数表示更早出现；使用明确的“提前 / 延后”文案。非法输入原位提示，既不提交也不静默截断。
- 显示实际生效值，命令失败保留上一次成功值，提示错误；不因调整失败停止视频。
- 当前没有字幕时禁用调整。暂停和跳转保持偏移；切集、换片源、换成另一条字幕或关闭字幕时归零。再次选中同一条已选字幕不归零。
- 同一播放条目和片源上的缓冲恢复保留偏移；显式重试重建播放条目、退出播放或重新打开则回到 0。不保存到磁盘，不按剧传播。
- 设置与观察 `sub-delay`，由 Core 快照传递实际状态，UI 不直接访问 Player。

## 5. 拖入本地字幕

### 5.1 接受范围

内置播放器已加载文件后接受拖放，播放、暂停或缓冲时均可用；尚未加载、失败或关闭过程中不接收。窗口、最大化和全屏的画面区域使用相同行为。拖入时提示“松开以加载字幕”。

首轮支持独立的 `.srt`、`.ass`、`.ssa`、`.vtt` 文件，大小写不敏感。目录、压缩包、文本 URL、没有可读取文件路径的虚拟附件，以及 `.idx + .sub` 等成对字幕不在本轮范围。扩展名仅作入口筛选；最终是否能加载由 libmpv 的结果确认。

### 5.2 加载与选择

- 单文件成功后加入菜单并立即启用；切换到新字幕时延迟归零。失败保持原字幕、原偏移和视频播放。
- 多文件按拖放数据提供的顺序逐个加入，只启用第一个成功项，其余供菜单选择。成功与失败混合时汇总提示，不为每个文件弹出对话框。
- 当前条目内，同一规范化绝对路径只加载一份；重复拖入重新选中已有轨道。如果该轨道本来就在使用，保留当前延迟。重复拖入不是“重新读取已编辑字幕”功能。
- 取得文件列表期间如果发生手动选轨、再次拖放或关闭字幕，以更新的用户操作为准；旧拖放结果不能重新抢回选中项。
- 同条目同片源的缓冲恢复保留本地附件；切集、换片源、显式重试重建条目或关闭播放后移除会话登记，不自动匹配下一集文件。显式重试后需要重新拖入。
- 文件只读使用，不上传到 Emby，不复制进应用持久缓存，不移动、不修改、不删除原文件。

### 5.3 条目与异步保护

WinUI 获取拖放数据是异步操作。开始时捕获当前会话和不透明的播放条目代际，Core 在受理、每次加载和处理完成结果时核对代际。只比较 `ItemId` 不够，同一集可能已重新播放。过期请求取消或返回安全提示，不能落到下一集。

拖入、手动切轨、首选语言自动选择和服务器字幕到达经过同一条串行会话控制路径。手选保护既要约束 C# 的自动选择，也要约束 `sub-add` 的原生选择副作用。当前 `sub-add ... auto` 在部分情形仍可能触发默认选择，不能把它当成绝对的“不切换”。

异步加载不得长时间占住会话收件箱，阻止关闭、切集和取消。原生命令的完成与事件处理需要明确关联到条目代际；过期加载不得污染新条目，即便原生层已经开始工作也要有取消或清理路径。具体实现通过可控假引擎和真实 libmpv 验证。

## 6. 模块与契约

数据流：WinUI 拖放 / 设置 / 轨道面板 → `Mambo.Core.Contracts` → Core 播放会话 → `IPlayerEngine` → libmpv；实际状态沿引擎事件 → Core 快照 → ViewModel 返回。

- `AppSettings`：增加音轨语言与字幕语言设置；旧字段缺失使用上文默认，未知值回退默认。继续使用 JSON 源生成和现有原子设置存储。
- `IPlaybackSession`：增加字幕延迟命令与本地字幕加载命令。既有选轨命令保留，交互命令明确绑定当前条目，防止排队后作用到新条目。
- `SessionSnapshot`：增加字幕实际偏移、本地字幕受理能力和不透明条目代际。代际不含服务器 ID、路径或令牌。
- `TrackInfo`：增加必要的安全展示字段与来源标识。UI 不接收原始 mpv 属性树或 Core DTO。
- 本地字幕请求持有路径的类型必须覆盖 `ToString()`，避免隐式输出路径；路径仅经请求进入 Core 和原生调用，不进入快照、日志、设置或异常正文。
- Core 分离语言选项转换、轨道投影和本地附件登记，避免将所有规则继续堆进 `PlaybackSession`。需要的拆分只服务本轮功能。
- `PlayerOverlay` 负责 WinUI Drop 与面板交互，`VideoSurface` 保持显示职责。拖放数据使用系统文件对象，传给 mpv 的命令使用参数数组。
- 用户文件与 Core 下载的临时字幕分别登记。既有临时字幕清理路径不能接触用户文件。

全套实现保持 AOT 兼容；XAML 只放 App，界面绑定使用 `x:Bind`，前端只使用 Contracts 和现有 VideoSurface 公开 API。Fake 会话同步支持新契约，演示模式不访问真实用户文件。

## 7. Emby 上报与错误

用户拖入的轨道不属于服务器媒体源，不能把其 `ff-index` 误映射为 Emby 字幕索引。服务器原有轨道继续准确映射；本地字幕选中时上报省略对应的服务器字幕索引，不发送文件名或路径。

本轮不实现服务器远程字幕校时。现有上报中固定为 0 的 `SubtitleOffset` 改为省略可选字段；本地偏移的真实状态只在播放器中展示。公开 Emby 文档对该字段类型的描述存在差异且未明确单位，本轮不猜测单位，也不把本地校时写入服务端偏好。

无效文件、加载失败、容量用尽、无字幕可调、目标条目过期使用固定中文错误与稳定错误码。批量加载部分失败保留成功项；加载失败不关闭视频，原字幕保持可用。原始 I/O 异常、原生输出与文件完整路径不进入日志。

## 8. 验证与完成标准

实现阶段需要覆盖：

1. 旧设置兼容、首选语言转换、下次会话生效、手选不跨集或重启保存；外置 mpv 不被设置覆盖。
2. 同语言多轨、缺失字段、重复标题、容量上限、选中项可见及字幕关闭。
3. 延迟的正负方向、0.1 秒步进、范围和失败回退；暂停/跳转保留、切集/换轨清零。
4. 单个/多个字幕、重复路径、损坏和不支持文件、部分成功，以及用户文件从未被修改或删除。
5. 拖放数据迟到、自然连播、手动切集、同集重播、字幕下载晚到、关闭字幕与再次手选的竞争；当前用户选择不被旧结果覆盖。
6. 本地字幕索引与 Emby 索引碰撞、停止上报和临时文件清理；无路径、文件内容或凭据泄漏。
7. 真实无头 libmpv 加载合成 SRT/ASS 并观察轨道和 `sub-delay`；界面专项验证输入焦点、Esc、拖放与控制层隐藏。

代码改动完成后运行 `dotnet build -p:Platform=x64`、`dotnet test`，以及对应 Native AOT 发布和针对本轮变更的界面检查。已完成的旧阶段验收不重新执行。

【需用户】从文件资源管理器拖入真实 SRT/ASS，确认字幕显示、校时方向、暂停及全屏行为；用真实 Emby 片源确认语言选择和服务器外挂字幕晚到时不会覆盖手选。自动化结果不能代替这些人工检查。

完成标准：四项能力可经正常界面使用；无持久化手选记忆；切集和退出无本地附件残留；失败不打断原视频；构建与必要测试通过，人工项状态如实记录。
