# 安装版与便携版的应用内更新

日期：2026-10-06。

用户指出每次下载完整安装包并重新走安装流程不方便，要求同时处理安装版和便携版。本次替换 GitHub 自动更新的安装方式，保留首次安装用的 Inno Setup 和现有用户数据位置。不推送或发布远端。

## 用户流程

设置页检查公开稳定版，点击“下载更新”后比对本地文件并准备更新。未变化的组件不下载；过程可取消，旧程序不被改动。准备完成后按钮变为“重启并更新”，再次确认后走主窗口既有保存播放进度、释放播放器、关闭后端和释放单实例的退出流程。独立更新器等原进程正常退出再替换文件，并重新打开应用。

安装版保留原目录、快捷方式、卸载入口，更新匹配安装目录的 HKCU DisplayVersion；便携版不创建安装注册信息。卸载时调用 helper 按当前发布清单清理更新新增文件，再由 Inno 删除其自身跟踪的文件。清理仅删除仍与发布哈希匹配的文件，不扫描用户数据目录。

旧版只有下载安装器的能力，必须先通过一次普通升级获取新更新器；不能声称已发布旧程序凭空获得此功能。开发输出没有 release-manifest/helper 时继续提供传统安装包入口；历史 Release 缺少组件清单时明确说明传统安装流程。

## 格式与边界

- 沿用公开 GitHub Releases 和现有 HTTPS 来源限制。`Mambo-X.Y.Z-win-x64-update.json` 先按 GitHub 资产 digest 校验，再读取其组件与逐文件 SHA-256。下载客户端不发送 Emby/GitHub 凭据或 Cookie。错误只有固定中文文案。
- 五个组件：app（应用、helper、PRI、XBF、发布清单）、runtime（Windows 运行库）、mpv（播放器和 shader）、assets（字体等资源）、licenses（许可和第三方材料）。这是按组件复用，不是二进制块差分；组件发生变化时下载该组件的完整 ZIP。支持跳过版本，无需维护相邻版本补丁链。
- 本地是否可复用由实际文件哈希决定，不只信任版本号或旧清单。缺失或损坏的组件会重新下载。整个组件 ZIP 和每个解压文件都校验；拒绝多余/重复 ZIP 条目、路径越界、Windows 路径别名、符号链接、文件/目录冲突与超限数据。
- 清单上限 2 MiB、单组件/文件 512 MiB、全部展开文件 2 GiB、文件数 10,000，最多五个组件。准备限时 15 分钟；helper 就绪限时 60 秒；等待原进程退出限时两分钟。取消不会强制关闭播放或终止主程序。
- `Mambo.Updater` 是独立 Native AOT 程序，无需终端 PowerShell 或用户安装 .NET。启动时复制到本轮缓存，固定 PID、启动时间与 Mambo.exe 完整路径共同验证父进程。helper 取得独占更新锁并再次校验文件后发出就绪信号，主程序才退出。
- 更新前备份所有将改动的现有文件，准备全部替换文件，再原子提交恢复日志。逐文件替换和最终校验失败时恢复原文件；旧发布删除的文件只有仍匹配旧哈希才删除。对已安装的相同/更新版本拒绝过期计划。
- 异常中断保留恢复日志/备份。下次进入程序入口时先运行恢复器；提交标记已经落盘时只清理。进程退出中断/断电不等于完整磁盘事务，若系统损坏到主程序无法进入入口，仍需用完整安装包修复；不承诺硬盘故障下自动恢复。
- 不进行权限提升。便携目录必须可写；只读目录在下载前提示。缓存只清理本次失败/取消的准备目录，或此前已完成、带结果标记且至少过一分钟的更新目录。
- PDB 保留在构建输出的 symbols/updater 目录，不再随用户包传输。

实现依据：[GitHub 发行资产 API](https://docs.github.com/en/rest/releases/assets)、[.NET Native AOT](https://learn.microsoft.com/en-us/dotnet/core/deploying/native-aot/)、[File.Move 覆盖行为](https://learn.microsoft.com/en-us/dotnet/api/system.io.file.move?view=net-10.0)。下载完整性与仓库来源验证不替代代码签名。

## 验证

- `dotnet build -p:Platform=x64` 为 0 警告 / 0 错误，锁定依赖还原通过；`dotnet test` 共 591 项，568 通过、23 项既有 GPU/性能测量用例按配置跳过，0 失败。更新专项合计 73 项，覆盖未变化组件复用、跨版本、损坏补全、取消、双层摘要、异常 ZIP、路径/大小限制、陈旧计划、文件锁冲突后的回滚、恢复日志及新增文件卸载清理。
- 主应用与独立 helper 的 Native AOT 发布通过。最终本地候选：`publish/releases/0.1.5/20261006-074624-541/`，安装器 112,838,609 字节，便携包 165,584,155 字节；应用组件 12,343,536 字节，清单 686,655 字节。相对于下载同版完整安装器，这次相同依赖的更新约需 13.03 MB，减少约 88.5%。运行时、播放器、字体、许可合计 354,085,206 字节直接复用。组件变化时仍会下载对应完整组件，不把此比例推断到所有未来版本。
- 最终应用清单共 3,291 个文件（含 release-manifest.json），没有 PDB；helper 为 3,343,872 字节。完整原生对应源码仍提供，897 份原生/Rust 源码校验与归档通过。
- 首轮真实进程测试发现 `GetProcessById` 对象未保留进程句柄，父进程退出后无法取得 ExitCode；该错误发生于写入前，旧文件保持原样。修正为在父进程存活时打开并保留句柄；修订后的安装/便携测试均通过正常退出、原位替换、重启与全部文件哈希校验。安装版版本登记和卸载新增文件通过，自定义文件保留；报告为 `artifacts/component-update-validation/14596bfd44b642b3ad3797cd04ceef16/result.json`。
- **最终交付包复验通过**：`artifacts/component-update-validation/0bd9e3e1e6aa45348e8eca14c5e77098/result.json` 中 portable/installed 均为 Passed，使用交付包内的 helper，没有覆盖诊断版本；均只使用 app 组件，全部 3,291 个发布文件哈希正确。旧进程与重启后的新进程均正常退出，安装登记更新为 0.1.5；卸载清理了模拟新增的诊断页文件、其他程序文件与注册项，自定义文件保留。本轮测试进程和测试安装已清理。
- `scripts/test-component-update.ps1` 在仓库内独立目录测试，应用仅使用内存假服务。检测到已有正式安装注册项时拒绝安装生命周期测试；测试快捷方式使用本轮独立分组。旧版夹具补入 helper，且移除一个未使用的诊断页文件以模拟新版新增文件；不把这个夹具描述为旧公开程序原生支持新协议。
- 未发布新 GitHub Release，组件 HTTP 下载由真实服务配合模拟响应验证，尚无新协议的线上端到端证据。本次没有执行全套物理界面输入、真实 Emby 播放中更新、GPU 或人工 HDR 验收。
