# 应用图标

日期：2026-10-06。范围：应用图标的图形、导出方式和接入位置。取代 `P2-design.md` D10 及其后各记录中「应用图标暂缓」的结论。

## 起因

P2 第 1 轮移除了蓝色方块加播放三角的草稿，图标一直暂缓，exe、任务栏和安装包显示的都是系统默认图标。用户于 2026-10-06 要求画图标。本稿是第一版；预览交给用户后，用户于同日要求发布新版本，没有提出修改。

## 决策

1. **图形。** 深色圆角方块上一个白色的 M：左肩是实心的播放三角，右边是一道斜线和一根竖线，圆头圆角。字母对应应用名，三角对应播放。
2. **配色跟随中性强调色。** 方块是 `#3B3D44` 到 `#17181B` 的竖向渐变，外沿一圈上亮下暗的细高光，图形纯白。不用彩色，理由同 `P9-neutral-accent.md`。深色方块在浅色和深色任务栏上都能辨认。
3. **不复用旧项目的图标，也不沿用 P2 的蓝色草稿。**
4. **逐尺寸生成。** 16 到 256 共 13 个尺寸各画一次，方块外沿、三角左边和竖线对齐到整像素；16 px 时方块铺满，其余尺寸留约 4% 的边。小于 256 的尺寸存 32 位位图，256 存 PNG。
5. **只嵌进 exe，不随程序另带文件。** 窗口图标从 exe 资源里取，发布目录和更新组件的文件清单不变。

## 实现与边界

- `scripts/build-app-icon.ps1` 是图形的唯一来源：按尺寸生成 SVG，用 Edge 无界面模式栅格化，写出 `src/Mambo.App/Assets/AppIcon.ico` 和矢量母版 `scripts/app-icon.svg`。只在改图标时运行，构建、发布和 CI 直接用已提交的 `.ico`。
- `Mambo.App.csproj` 用 `ApplicationIcon` 嵌入图标；WinUI 默认会把 `Assets/` 下的文件当内容带出，这里把 `.ico` 排除。
- WinUI 窗口类没有图标（实测类图标为空）。`Windowing/WindowIcon.cs` 在主窗口创建后按当前 DPI 取大、小两份图标交给窗口，供任务栏、Alt+Tab 和任务视图使用。自绘标题栏不显示图标。诊断窗口没有接。
- 安装器用 `SetupIconFile` 指向同一份 `.ico`；「应用和功能」里的图标原本就取自 `Mambo.exe`。
- 更新程序 `Mambo.Updater.exe` 没有接图标。

## 验证（2026-10-06，本机）

- 用另一套解码器读回 `.ico`：13 个尺寸齐全，四角透明，深浅两种底色下逐尺寸看过，16 / 20 / 24 / 30 / 32 px 放大后边缘落在整像素上。
- Debug 构建 0 警告 / 0 错误；`dotnet test` 共 609 项，586 通过、23 按配置跳过、0 失败。
- Debug 的 `Mambo.exe` 含 13 项的图标组，按 16 到 64 px 取出的都是对应尺寸；输出目录的 `Assets/` 下只有字体。
- 演示模式实际启动一次：窗口报告的大、小图标为 48 和 24 px（本机 150% 缩放），画出来是新图标，窗口正常关闭。启动时请求了最小化且不激活，应用没有照办，窗口出现并取得了前台约两秒。
- 本地 Native AOT 发布成功，日志没有警告；发布出的 `Mambo.exe` 同样含 13 项的图标组并能按尺寸取出，发布目录的 `Assets/` 下只有字体。AOT 版没有再启动一次，窗口图标的依据是同一段代码在 Debug 下的实测。
- 用只含许可文件的空目录编译了一次安装器，安装程序的图标是新图标。
- 任务栏、Alt+Tab 和开始菜单里的实际观感没有看过，需要用户确认。
