# Mambo 设计稿（P2 定稿）

> 布局与交互识别度继续参考原版，动效采用用户确认的「克制、有辨识度」语言，见 [P9：视觉基准与统一动效](../docs/decisions/P9-visual-parity.md)。本目录保留历史 P2 原型；公共 token 继续与 WinUI 同步，原型兼容不等于 WinUI 视觉验收。

可点击的 HTML 原型，按 1 DIP = 1 CSS px 绘制。2026-10-02 用户确认定稿：`tokens.css` 已转换为 `src/Mambo.App/Themes/Tokens.xaml`，结论见 `docs/decisions/P2-design.md`。之后改 token 时两边同步。

## 当前公共动效规范

| token | 时长 | 语义 |
|---|---:|---|
| `--dur-press` / `MotionPressDuration` | 80 ms | 按下反馈 |
| `--dur-exit` / `MotionExitDuration` | 120 ms | 独立退出 |
| `--dur-feedback` / `MotionFeedbackDuration` | 160 ms | hover、刷色、冷图/弹层/控制栏进入 |
| `--dur-content` / `MotionContentDuration` | 240 ms | 页面、详情前景、Hero 文字、筛选占位 |
| `--dur-image` / `MotionImageDuration` | 400 ms | 背景换图纯淡变 |
| `--dur-mode` / `MotionModeDuration` | 480 ms | WinUI 浏览↔播放翻折 |

三曲线：`--ease-out=(.2,.8,.2,1)`、`--ease-in=(.4,0,1,1)`、`--ease-symmetric=(1/3,0,2/3,1)`，对应 XAML `Motion*KeySpline`。平台刷色与原生按距离滚动不冒称自定义曲线。

卡片只做 Y−2 / 按下 Y−1 的轻反馈；普通按钮没有缩放，计数直接更新。删除封面飞行、逐卡揭示、Hero 子项延迟和背景放大、标题逐字推移。一次动作只有一个主入场 owner。

历史 HTML 播放容器沿用 Content，不把 Mode/Symmetric 强塞给抽屉。关闭等实际动画完成，快速重开由 generation 隔离。审阅「减少动画」与 `prefers-reduced-motion` 合成生效：立即取消在途动画、落最终样式，停自动轮播/循环/平滑滚动；恢复不重播现有节点。不使用 1 ms 无限动画伪装关闭。

## 查看方式

在仓库根目录启动本地 HTTP 服务，再用浏览器打开（这样才能加载仓库里的 MiSans 字体）：

```bash
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8765/design/>。

直接双击 `index.html` 也能看。不过浏览器会拦截 `file://` 下的字体，界面会回退到系统字体。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 原型入口：窗口外壳 + 右侧审阅面板 |
| `tokens.css` | 设计 token：颜色（浅色 / 深色 / 播放层）、控件、字体阶梯、间距、圆角、外壳与卡片尺寸、动效 |
| `prototype.css` | 布局与组件样式 |
| `prototype.js` | 演示数据、程序化插画、页面与播放层逻辑 |

所有图片由 `prototype.js` 里的程序化生成器绘制，没有使用任何外部或旧项目素材。片名、简介、人物都是虚构的。

## 怎么审阅

- 右侧面板可以切换窗口尺寸（1500×860 / 最小 1100×720）、主题（跟随系统 / 浅色 / 深色）、登录状态，并一键跳到各页面和播放状态。
- 窗口较窄时面板会自动收起，点右上角"显示审阅面板"即可展开。
- 打开"显示改动标注"后，相对原版有改动的元素会用橙色虚线框加编号标出。
- 原型本身也能直接操作：点侧栏、卡片、播放按钮、筛选和排序；播放时可以用快捷键。

## 保持不变（与原版一致）

- 无边框亚克力浅色外壳；40px 标题栏（后退 / 前进 + 居中标题，首页显示 hero 分页点）；208px 侧栏。
- 侧栏：40px 导航项、半粗体文字、激活态加左侧 3×16 主色条。
- MiSans 字体、主色 #0c68b8、评分色 #e5a00d。
- 海报 150×220、横版 300×169 的卡片，评分徽标、进度条、悬停上浮。
- 首页 hero 轮播（7 秒，整块点击进详情）+ "最近播放" + 各库"最新"卡片行。
- 详情页：hero、季胶囊、剧集横向列表、演职人员。
- 资料库：类型 / 年代 / 分级筛选（组内"或"、组间"与"），五种排序。
- 播放页：打开中（20 秒后提示加载较慢）、缓冲、失败、倍速、字幕 / 音轨、选集、快捷键 `空格 M [ ] C V , . ←→ ↑↓ F11 Esc`。
- 弹出面（菜单、对话框、通知）：半透明浅底 + 白色描边 + 模糊 + 柔和投影。

## 历史 P2 实现提示（布局以 P9 为准，动效已同步）

- **文案**：界面不加解释性说明文字，只保留标题、数值、状态和必要的错误信息。`docs/PLAN.md` 附录 A 里的提示类文案（登录表单的 HTTPS 提示、筛选规则说明、加载计数、"已经到底了"等）不显示；对话框正文压到一句。
- **窗口背景**：`DesktopAcrylicController`，强制保持激活外观。原型中的 tint 只是示意，以系统亚克力为准。
- **内容区**：与外壳同一层，不另加底色；距标题栏 12px，左、上 1px 描边（浅色黑 10%，深色白 10%），左上、右上圆角 12。
- **控件**：
  - 按钮：尺寸以当前 token 为准；圆角、柔和底色与描边保留。悬停/按下只改变颜色与描边，不缩放；键盘焦点保持清晰。
  - 输入框：底色黑 2.5%，1px 黑 18% 描边；聚焦时主色描边加 3px 柔和光环。
  - 主操作按钮用主色实心；危险操作在确认对话框中用红色文字。
- **hero 底部渐隐**：用 `CompositionMaskBrush` 配线性渐变遮罩，不要叠一层纯色。底部向下延伸 96px，与卡片行衔接。
- **卡片悬停**：Y−2 DIP，按下 Y−1 DIP；分别使用 Feedback / Press 和 EaseOut。换绑、卸载、禁动画时停止复位，不把旧 hover 带给新条目。
- **横版网格**（最近播放、搜索结果）：列数 = floor((可用宽 + 16) / (240 + 16))，卡片拉伸填满整行，图片保持 16:9。窗口 1100 宽时 3 列，1500 宽 4 列，1920 宽 6 列。在 `SizeChanged` 时重算 `ItemWidth`。首页卡片行仍用固定的 300×169，横向滚动。
- **海报网格**（资料库）：固定 150×220，列间距在 20 以上自动分配，两端对齐。
- **播放层**：
  - 画面上方不用亚克力：控件、菜单、抽屉、"即将播放"卡、通知都用半透明或不透明的纯色。
  - 播放时标题栏切到深色；全屏时标题栏隐藏，播放层顶部显示片名。
  - 控制层空闲 3 秒自动隐藏；只有画面区域内的指针移动才会唤出控制层。
- **菜单与对话框**（浏览区）：原版弹出面，可以用应用内亚克力；对话框按钮靠右，顺序为"取消、确认"。
- **动效**：遵循上方六档语义与三曲线。WinUI 唯一强动效是中心翻折；历史 HTML 不承担其证明。系统关闭动画直接终态，原生控件按平台策略单独观察。

- `node --check design/prototype.js` 通过；一次性迁移检查确认 CSS `var()` 均有声明，六档时长与 XAML 一致，退休的封面克隆节点、别名和逐卡延迟已移除。

- 实际检查 1500×860、1100×720 原型窗口；未登录标题仍为完整两行。布局截图保留在本地 `artifacts/motion-prototype-large.png`、`motion-prototype-small.png`。
- 审阅开关与浏览器 `prefers-reduced-motion` 分别验证首次加载及运行中切换：有效 reduced 状态无无限动画、延迟透明内容或平滑滚动；恢复后不补播已结束动作。标签与本轮 HTTP 服务已关闭。
