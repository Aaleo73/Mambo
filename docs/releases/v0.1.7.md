Mambo 有了自己的应用图标。

- 新图标是深色圆角方块上的白色 M，左半边是一个播放三角；配色与界面的中性黑白一致。
- 程序文件、任务栏、Alt+Tab、任务视图、安装程序和「应用和功能」列表都会显示它，不再是系统默认图标。
- 图标按 16 到 256 像素逐个尺寸绘制，小尺寸下边缘保持清晰。

更新后，桌面或开始菜单的快捷方式可能要过一会儿或重新登录后才换成新图标，这是系统的图标缓存造成的。

Windows x64 构建通过，全套测试 586 项通过，23 项 GPU / 性能测量用例按配置跳过。

v0.1.5 及以上版本可在设置中检查更新；更早版本可下载新的安装包或便携包升级。
